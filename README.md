# Aura
Aura es un espacio web interactivo enfocado en el bienestar, la atención plena (mindfulness) y la armonía visual. 
# 🧘‍♀️ Aura: Espacio de Atención Plena

El concepto detrás de Aura:La idea central es que la tecnología no debería ser una fuente de estrés, sino una herramienta que nos ayude a volver al presente. Aura funciona como un "espejo" donde el usuario puede volcar cómo se siente, por qué está agradecido y qué intención quiere darle a su día, creando un espacio seguro donde sus emociones son escuchadas y validadas.

Cómo ayuda Aura a sus usuarios:Es un espacio sin juicios: A través de un diario de emociones, el usuario puede identificar patrones físicos y mentales. No es solo marcar una casilla, es entender si hoy me siento "con energía" o "necesito pausa" y aprender qué factores influyen en esos estados.Cultiva la gratitud: Hemos diseñado un espacio de gratitud express que invita a la reflexión rápida. Es un ejercicio sencillo para entrenar a nuestra mente a buscar lo positivo en el día a día.

Aporta dirección: La "Intención del día" actúa como una brújula. Al empezar la sesión, el usuario recibe un pensamiento positivo que le ayuda a enfocar su energía mental durante el resto de la jornada.

Personalización humana: Creemos que no hay dos mentes iguales. Por eso, Aura se adapta a la personalidad de cada usuario (si alguien es más analítico, verá estadísticas de su progreso; si es más creativo, disfrutará de una interfaz más visual y estimulante).

Mi visión como desarrolladora:Para mí, Aura es mucho más que HTML, CSS y JavaScript. Es la demostración de cómo el diseño centrado en el usuario puede cambiar nuestra relación con las pantallas. Al combinar una interfaz suave y minimalista con una lógica de datos que respeta la privacidad del usuario (todo se guarda en su propio dispositivo), he querido crear una experiencia que transmita paz desde el primer clic.

## 🛠️ Aspectos Técnicos
Este proyecto ha sido desarrollado siguiendo un enfoque **Vanilla First** (sin frameworks pesados), priorizando el rendimiento y el dominio profundo de los fundamentos web:

- **HTML5 Semántico:** Estructura clara, accesible y SEO-friendly.
- **CSS3 Moderno:** Implementación de *Glassmorphism*, Variables CSS para temas dinámicos, Flexbox y CSS Grid para layouts totalmente responsivos.
- **JavaScript (Vanilla ES6+):** Gestión de estado compleja, manipulación dinámica del DOM, manejo de eventos y almacenamiento persistente mediante `localStorage`.
- **Arquitectura de Datos:** Implementación de persistencia local para guardar perfiles de usuario, historiales de actividad y preferencias sin necesidad de backend externo.

## 🌟 Funcionalidades
- **Onboarding Personalizado:** Sistema de registro que adapta la interfaz a la personalidad del usuario (Analítico, Creativo, Sensorial, Balanceado).
- **Mood Tracker:** Registro cronológico del estado de ánimo con persistencia de datos.
- **Micro-Diario:** Espacio seguro para registrar pensamientos de gratitud e intenciones diarias.
- **Diseño Mobile-First:** Experiencia optimizada para móviles, priorizando el uso táctil y la fluidez.
